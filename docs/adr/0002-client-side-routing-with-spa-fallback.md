# Клиентский роутинг через React Router и SPA-fallback

Для маршрутов `/` и `/book` используем React Router с `BrowserRouter`. Fastify при наличии собранного фронтенда отдаёт `index.html` для не-API маршрутов, поэтому прямые ссылки и перезагрузка страницы в контейнере не дают 404. Альтернатива с hash-роутингом отклонена: она ухудшает URL и SEO.

## Considered Options

- **Hash-роутинг** — проще в статическом хостинге, но URL вида `/#/book` хуже для пользователя и поиска.
- **History API + SPA-fallback** — выбранный вариант.
