# Главная страница — статичный лендинг, запись начинается на `/book`

Главная страница рассказывает о сервисе и ведёт на отдельный маршрут `/book`; каталог типов встреч и форма бронирования не входят в лендинг. Так главная остаётся простой в поддержке и не смешивает маркетинговый контент с потоком записи. До реализации бронирования `/book` — заглушка.

## Consequences

- Каталог типов встреч появится на `/book` или его дочернем маршруте на следующем шаге.
- Главная не загружает данные из API.
